macOS first-launch help (the Mac build is not yet signed by Apple)

Drag Kestral Budget to your Applications folder, then open it. What happens next depends on your Mac:

If macOS says it “cannot verify” the app or that it is from an unidentified developer: open System Settings → Privacy & Security, scroll to the message about Kestral Budget, click Open Anyway, and confirm.

If macOS says the app is “damaged and can’t be opened”: the app is not damaged. macOS is blocking it because it is unsigned. Open Terminal, run the command below, then open the app again:

xattr -cr "/Applications/Kestral Budget.app"

This clears the download quarantine flag on that one app. Only do this for software you trust. The full source code is public on GitHub.

Kestral is free. If it’s useful, you can support development.

Kestral has no automatic bank connections, cloud sync, or automatic backups. Export backups of important data regularly.
