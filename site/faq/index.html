Frequently asked questions

Quick answers about privacy, platforms, backups, and getting started.

Does Kestral Budget connect to my bank?

No. There are no bank connections. You enter and categorize transactions yourself, so no one gets your bank login.

Is it really free?

Yes. There is no subscription, no trial, and no paid feature tier. If you find it useful, you can support development on Ko-fi.

Where is my data stored?

On your own computer. The desktop app keeps it in a local database, and a self-hosted copy keeps it in the database volume you configure. It is not sent to a cloud service. See the privacy page for details.

Which platforms are supported?

The desktop app is available for Windows (x64) and macOS (Apple Silicon). You can also self-host it with Docker, Portainer, or Podman on your own computer or server.

Does it sync between devices?

No. There is no cloud sync. The desktop and self-hosted editions use separate databases, and you can move data between them with Export backup and Import backup.

How do I back up my budget?

Backups are manual. Use Export backup in the app to save a file, and Import backup to restore it. Keep copies of anything important.

How many categories and budget items can I have?

As many as you like. You choose the sections, categories and items that fit your life, and you can set your currency, date format, theme and layout.

Why does macOS say the app is damaged or cannot be verified?

The Mac build is not yet signed or notarized by Apple, so Gatekeeper may block the first launch. The app is not damaged. If macOS says it cannot verify the app, open System Settings → Privacy & Security and click Open Anyway. If it says the app is damaged, run xattr -cr "/Applications/Kestral Budget.app" in Terminal and open it again. Only do this for apps you downloaded from the official release page.

Is the source code available?

Yes. Kestral Budget is open source under the GNU Affero General Public License v3.0 or later. The code is on GitHub.

Can I use it on a server for several people?

The app has no accounts or login, so do not expose a self-hosted copy to an untrusted network. It is designed for personal use on a network you trust.
